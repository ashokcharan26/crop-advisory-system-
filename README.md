# GreenGuide — AI-Assisted Crop Advisory Prototype

A small static website for a student project. It uses HTML, CSS, and JavaScript and can be hosted on GitHub Pages.

## Features
- Sample crop ideas based on soil type and season
- General water availability guidance
- Safe first-step plant health guidance
- A rule-based demo farming helper (not a live AI model)
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `crop-advisory-system`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open repository **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages URL to appear in Settings → Pages.

## API keys and backend
This prototype does not need API keys or a backend. Do not put private API keys in browser JavaScript or a public GitHub repository. GitHub Pages hosts static files only; a real AI API or live weather integration requires a separate server/backend (for example, a serverless function) to keep secrets safe.

## Important
Crop examples are educational placeholders. Confirm crop choices and treatments with local agricultural experts and current local conditions.
